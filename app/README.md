# Five Metal Masonry (FMM) — Sacred Bronze Iconography Archive & Scholar Discovery Engine

Computational discovery engine and curatorial repository preserving and analyzing sacred South Indian bronze sculpture (Chola, Pallava, Vijayanagara traditions).

## Features
- **Scholar-First Search**: Thematic re-ranking prioritizing Theme Affinity (50%), Curatorial Confidence (30%), and Text Relevance (20%).
- **Interactive Multi-Slide Carousels**: High-resolution plate browsing with thumbnail filmstrips and query hit indicators.
- **Layer 2 OCR Ingestion Studio**: Windows Native OCR extraction with automated Sanskrit IAST diacritic repair (*Gaṇeśa*, *Āsīna*, *Mūṣika*, *Triśuṇḍa*).
- **Archive Data Studio**: 18-table relational catalog partitioned across Core Content, Controlled Taxonomy, Geography & Eras, and Access/Telemetry.
- **29 Bespoke Classical Icons**: Zero cartoon emojis; custom Shilpa Shastra vector iconography.
- **Embedded DuckDB Engine**: High-performance analytical SQL queries running in-container.
